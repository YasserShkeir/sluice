Generic rules

Masks authorization · cookie · set-cookie · proxy-authorization, any credential-shaped header name, Bearer … values, and token=-style fields.

App-registered shapes

Slack adds xox*- and two headers; Gmail adds its XSRF header. Registered for all traffic, not just that app's.

publicParams

The one rule that preserves a value: fast.com's token is public, and masking it would make the capture unreplayable.

11 tables + 2 FTS

captures · workspaces · actors · containers · items · edges · sessions · cursors · interaction_flows(+_steps) · flow_templates

Contentless FTS

captures_fts and items_fts index the plaintext but store no second copy; results join back on rowid.

Nowhere to put a secret

There is no credentials table. Only a redacted session descriptor — kinds, never values — is persisted.

API catalog

sluice apidoc groups captures by method + host + path into a Markdown endpoint reference. Scope it with --host.

Per-app tables

materialize() mines top-level response arrays — not parsed entities — into typed <app>_* tables, rebuilt as traffic arrives.

Flows & templates

learn-flows clusters bursts into flows and distils multi-step templates with per-step timing and parameter bindings.

Schema changes are additive by construction: CREATE TABLE IF NOT EXISTS does nothing to an existing database, so a new column goes in both the create statement and the additive-column map, and its index runs only after the ALTERs.
